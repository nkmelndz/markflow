# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately so we can address it promptly.

- **Preferred channel:** Open a private security advisory at https://github.com/nkmelndz/markflow/security/advisories/new
- **Please avoid** opening a public issue for security-related concerns.

We will acknowledge your report and work with you on a fix timeline as quickly as possible.
